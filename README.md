# Obito Gaming — сайт для Counter-Strike 1.6

Полноценный сайт без внешних зависимостей: регистрация и вход, админ-панель, список серверов с онлайном, автоматический рейтинг игроков, магазин привилегий, форум, новости с комментариями, банлист, форма контактов.

## Запуск

Нужен Node.js 22.13 или новее: https://nodejs.org

```bash
node server.js
```

Откройте http://localhost:3000 и зарегистрируйтесь — первый аккаунт автоматически становится администратором. Затем в админ-панели: Серверы → добавьте IP и порт вашего CS 1.6 сервера.

Переменные окружения (необязательно): `PORT` (по умолчанию 3000), `DATA_DIR` (где лежит база, по умолчанию ./data), `TRUST_PROXY=1` (если сайт стоит за nginx), `POLL_MS` (как часто опрашивать серверы, по умолчанию 20000).

## Как работает рейтинг

Сайт каждые 20 секунд спрашивает ваши игровые серверы по UDP (протокол A2S, который CS 1.6 поддерживает сам): кто на сервере, сколько фрагов, сколько времени. Эти данные копятся в базе — плагины на сервере не нужны.

Условие: игровой UDP-порт сервера должен быть доступен с компьютера, где запущен сайт. Смерти и хедшоты по этому протоколу узнать нельзя, поэтому в рейтинге: время, фраги, заходы, фраги/час.

## Размещение в интернете

Любой VPS/хостинг с Node.js: `node server.js` (лучше через pm2 или systemd) + nginx с HTTPS на порт 3000, `TRUST_PROXY=1`.

Резервная копия — папка `data/` (файл site.db).

## Что настоящее, а что нет

- Пополнение баланса: игрок создаёт заявку и переводит деньги на вашу карту, вы проверяете перевод и нажимаете «Зачислить» (админка → Пополнения). Автоматически перевод на карту сайт увидеть не может — для этого нужна платёжная система.
- Выдача привилегии на игровом сервере (`users.ini`) — вручную; в разделе «Заказы» отмечайте «Выдано».
